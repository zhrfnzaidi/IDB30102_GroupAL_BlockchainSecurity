# Dataset Description

## Dataset 1: SmartContractBenchmark
- **Source:** Public repository (as used by Deng et al., 2023)
- **Type:** Labelled smart contracts with vulnerability annotations
- **Representations:** Source code, Opcode, CFG
- **Size:** 100
- **Vulnerability Types:** Reentrancy, Integer Overflow, Timestamp Dependence, Access Control

## Dataset 2: Ethereum Vulnerable Dataset
- **Source:** Public repository (as used by Tang et al., 2023)
- **Type:** Smart contracts with known vulnerabilities
- **Representations:** Source code, Opcode

## Dataset 3: Control-Flow Graph Dataset
- **Source:** Public repository (as used by Deng et al., 2023)
- **Type:** CFG representations of smart contracts
